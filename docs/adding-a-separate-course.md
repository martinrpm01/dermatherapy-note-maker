# Add a separate course while another course is still treating

Use the patient's existing record and **Add Course**. The ongoing course can remain active while the next course has its consultation and setup.

**Before you begin:** Save any current work, then use the updated app for this workflow. In the browser or on iPad, use the refresh banner, or go to **Settings > Check for Updates > Refresh Now** when offered. On Windows, go to **Settings > Check for Updates**, select **Download Installer** when offered, and install the update.

## Create the new course and consultation

1. Find the patient and select **Open Patient**, then **Add Course**. Keep the existing patient record.
2. In **New Consent / Path Intake**, enter the new course's lesion, diagnosis, biopsy details, and **Sim / Consult Date**. Review the standard form defaults for this course, then select **Save Intake**.
3. The new course is selected automatically under **Pending Sim / Consent**. Check the lesion. If needed, use the course dropdown beside **Edit Patient** to select the new course, or **All Courses** to find it.
4. On the new course's card, select **Complete Course Setup**. Enter and review its setup, then select **Save Course**. Both courses may now show **active**. This does not complete the older course or record a treatment fraction.
5. On the new course, select **Start Sim / Consult**. Confirm the course name, lesion, visit date, and **Visit Type: Sim / Consult** before entering the consultation.
6. Add photos or attachments only if needed for this consultation. Use **Attach Sim / Consult Photos** for photos belonging to this note. Review **Note Preview**, then select **Finalize** when ready, or **Save Draft** to finish later. Saving the consultation does not start treatment or count a fraction.

## If you already started

If the new intake is already saved, select that pending course and continue from step 4. Do not add it again. If its consultation already exists, select **Open Sim / Consult** to reopen it.

Changing **Visit Type** inside the ongoing course does not create a separate course. Start with **Add Course** and select the new course first.

## Continue today's ongoing treatment

Select the ongoing course in the course dropdown, then choose **Start Today's Note** on its card. Confirm the lesion and treatment number. Keep that course active until its treatment is actually completed.

## What stays separate

The same patient identity and identification photo remain available. Each course has its own lesions, treatment setup, fraction history, consultation, notes, treatment photos, course documents, and note PDFs. A new course starts without the older course's visits or photos. Standard form defaults are not copied treatment history.

If the old lesion, a treatment number, or old-course photos appear in the new consultation, return to the patient and check the selected course before finalizing. Do not delete historical notes or the older course to create the new one.
